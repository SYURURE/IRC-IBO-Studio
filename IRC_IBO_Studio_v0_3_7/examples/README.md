# 人工サンプルの出典

synthetic_water_bend.xyz は tools/generate_demo.py で新規生成した71構造です。
O–H距離を0.96 Åとし、H–O–H角を98°から110°へ等間隔に動かしただけの架空の座標列です。
Gaussian・GRRM・IboViewによるIRC、構造最適化、振動解析、実験測定の結果ではありません。
エネルギー、波動関数、実時間、遷移状態の情報は含みません。操作確認のみに使用してください。
外部で各点の電子状態を計算しても、この座標列がIRCになるわけではありません。
元の研究データから数値を転用していません。docs/structure_preview.png はこの人工座標から再生成しました。
テストのGaussian風ログはテストコード内で作る人工的な書式検証用データです。
このリポジトリにはGaussian本体・IboView本体・非公開研究ログを含めません。

再生成：python tools/generate_demo.py
